# Игры с Рыжиком

Детские игры с лисёнком Рыжиком для малышей 3–6 лет в одном приложении: тайная картинка, мозаика, «Вырасти сад» (слияние как 2048, только без цифр), найди пару, тени, одень Рыжика и раскраска.

Без рекламы, таймеров и проигрышей. Всё работает офлайн: без внешних CDN, онлайн-шрифтов, аналитики и трекинга, в том числе из Беларуси и России. Прогресс хранится только на устройстве (localStorage / IndexedDB).

Сайт: https://pavellahutsin.github.io/ryzhik-igry/

Устройство приложения и правила каждой игры описаны в [PLAN.md](PLAN.md).

## Как запустить

Нужен Node.js 20 или новее.

```bash
npm install
npm test
npm run dev
```

Откроется на http://127.0.0.1:5173/

Сборка для публикации:

```bash
npm run regions   # проверка областей заливки у раскрасок (QA-отчёт)
npm run build
npm run preview   # http://127.0.0.1:4173/ryzhik-igry/
```

Публикация на GitHub Pages идёт через Actions (ветка `main`, папка `dist`): тесты, проверка раскрасок, сборка. В настройках репозитория источник Pages должен быть «GitHub Actions».

## Скриншоты и проверка в браузере

```bash
npm run build && npx vite preview &
npm i -D --no-save playwright && npx playwright install chromium
SHOTS_DIR=shots node scripts/shots.mjs
```

Скрипт открывает каждую игру в размере телефона (390×844), немного играет, сохраняет снимки и падает, если в консоли есть ошибки.
