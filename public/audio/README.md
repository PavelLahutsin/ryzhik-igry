# Озвучка и музыка (по желанию)

Положите файлы сюда и пересоберите (`npm run build`) — игры подхватят их сами, код менять не нужно:

- `voice/v01.mp3` … `voice/v37.mp3` — фразы Рыжика (список и когда звучат: `src/shared/voice-lines.ts`);
- `music/m01.mp3` … `music/m11.mp3` — фоновая музыка миров (включается в «Родителям»), `music/m12.mp3` — победный джингл.

Нет файла — звучат синтезированные звуки, как сейчас. Коды — из `prompts/ryzhik-igry-prompts.md`.
Советы: моно/стерео mp3 96–128 кбит/с, громкость выровнять (около −16 LUFS), у музыки бесшовная петля.
